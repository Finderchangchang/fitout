# 企业档案

给 `scripts/fitout.mjs` 用。复制下面各节，换成这一家的事实。每一项不知道就空着，或写「待补」。空着和「待补」都不会写进网站。不要为了填满而编电话、价格、人数、证号、评价。

练习、演示、虚构公司，名字后面加「（虚构）」。文件用 UTF-8。

填好的例子在 `examples/profiles/`。

## 1. 一句话介绍

写这家在哪个城市、做什么、卖给谁。一两句。不知道就空着。

（在这里写）

## 2. 基本信息

| 项 | 内容 | 怎么填 |
|---|---|---|
| 公司全称 |  | 工商注册名。没有就空着。 |
| 品牌名 / 门店名 |  | 网站上要出现的名字。练习请加「（虚构）」。 |
| 站点 id |  | 小写字母、数字、连字符，例如 `xiangkou`。这是目录名，不要用中文。 |
| 行业 |  | 做什么，一句，带上细分。例如「社区奶茶，不招加盟」。拿不准细分就只写行业。这格空着就不能挑样板间。 |
| 城市、地址 |  | 一行能用来导航的地址。没有就空着。没有地址就拼不出联系页。 |
| 电话 |  | 给人打的号码，例如 `0571-86001188`。没有就空着。空着不能开工。 |
| 微信 |  | 微信号。没有就空着，不要编。 |
| 邮箱 |  | 没有就空着。 |
| 备案号 |  | 有 ICP 再填原文。没有就空着。 |
| 营业时间 |  | 例如「每天 11:10-21:40」。某一天不确定就先写确定的那段。空着不能开工。 |

## 3. 主营产品 / 服务和价格

每样一行：名称、价格、包含什么、适合谁。没有价格就写「不标价」，不要编一个整齐的数字。不知道的产品整行不要写。

|---|---|---|---|
|  |  |  |  |

## 4. 优势和数字

只写能公开的事实，数字照原样写。没有数字就不要写「很多」「领先」「第一」。不知道就空着。

## 5. 团队

有真人再写名字和分工。没有就空着，不要编人名。

## 6. 资质

证照名称可以写。证号没有就空着，不要编号。

## 7. 是否招加盟 / 门店数

写招不招、几家店、各店地址。只有一家、不招加盟，要写明。不知道就空着，空着就当成没有加盟、不写门店分布。

## 8. 口号

一句要出现在首屏的话。没有就空着。不要另编一句广告语。

## 9. 客户会问的问题

有标准答案再写问题和答案。没有就空着。答案里不确定的，写「待补」，不要猜。
