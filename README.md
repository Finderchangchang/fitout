# 精装 · FitOut

> 便宜模型，也能装出好门面。

🚧 **开工中**（2026-10-05 立项）。[精酿 · BrewReel](https://github.com/Finderchangchang/brewreel) 的兄弟项目：精酿出片，精装出官网。

给中小企业一键生成**好看、统一、拎包入住**的官网：读企业档案，选一套装修风格，出一个单文件 `index.html`，传上 GitHub Pages 就能上线，手机打开不乱。

## 要解决什么

让 AI 给小公司做官网，常见的结果是：
- 每次长得都不一样，同一个人做十家，十种水平；
- 一股 AI 味：紫色渐变、居中大标题、三列图标卡片；
- 换成便宜模型，排版就崩。

精装的办法和精酿一样：**审美写进配方，模型只填空。**

## 怎么做

| 装修行话 | 在精装里是什么 |
|---|---|
| **装修风格** | 配色、字体、字号阶梯、间距、圆角，全部写成数值，模型不碰 |
| **户型** | 行业配方：门店服务 / 工厂贸易 / 教培 / 专业服务，各自的板块顺序、语气、信任要素 |
| **构件** | 首屏、服务、优势、案例、评价、常见问题、联系……每个板块 2–3 种版式 |
| **开工** | 模型按企业档案填内容、选版式，脚本拼成单文件官网 |
| **交房** | 一个 `index.html` + 图片文件夹，没有构建步骤，直接上线 |

流程：**量房**（读企业档案）→ **选风格** → **出效果图** → **交房**。

## 出图纸：学方法，不学长相

每套装修风格都从好作品里来，但不照搬：
1. 拆解优秀的企业官网和开源模板，量出真实的配色、字号、间距、板块顺序；
2. 只留骨架（结构、节奏、版式原则）；
3. 皮肤（配色、招牌细节、固定句式）全部换成我们自己的；
4. 过原创性检查：熟悉原站的人一眼看得出不是同一家。
