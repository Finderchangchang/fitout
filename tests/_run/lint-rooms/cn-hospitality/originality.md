# cn-hospitality 原创性记录

民宿客栈的国内风样板间。骨架沿用「实心页头、右上热线、首屏轮播、房型、吃饭、周边、游记、订房带、深色页脚」。皮肤按午后的院墙重做：苔绿只铺按钮和当前项下划线，纸是暖沙。

## 1. 保留的骨架

| 骨架 | 我们怎么用 |
|---|---|
| 页头 | 店名在左，七项导航，右侧订房热线，实心暖沙底，不叠在图上 |
| 首页顺序 | 轮播、四数字、四种房型、院子、故事、周边、晚饭、三篇游记、订房带 |
| 内页 | 统一页头加面包屑。房型写面积和参考价。周边按景点、体验、美食分。联系页热线和两枚码分开，留言另起一块 |
| 动效 | 轮播 4 秒，悬停暂停，数字进视口后计数 |

## 2. 重做的皮肤

### 2.1 配色

主色是压暗的苔绿，比稻黄更绿，也比松绿更暗。纸是暖沙，字是墨。价格用一小块暖褐。大面积不铺正绿，也不铺褐。

| 用途 | 参考片的做法（抽象） | 我们的做法 | 色值 |
|---|---|---|---|
| 背景 | 纯白 | 暖沙纸 | #F3EDE0 |
| 主色 | 鲜绿或霓虹绿 | 压暗的苔绿 | #092B08 |
| 强调色 | 橙、红，或近黑 | 栗褐，只标价格 | #564639 |
| 字 | 纯黑或纯灰 | 墨 | #2C291F |

### 2.2 字体处理

标题用宋体栈，正文先排西文无衬线再接中文黑体。首屏标题 72px、字重 700，左对齐，是活字，不烤进图，也不竖排。

### 2.3 角色

店主是院门边的实拍，不是西装抠图。房间和院子要求实拍。菜是浅底棚拍。

### 2.5 固定文案句式

按钮固定为「电话预订」「看看房型」「写给前台」。首屏是「今晚住进这处院子」。栏目用民宿故事、房型介绍、周边玩法、餐饮、游记、预订交通。相册从院子那一条进去，不占导航。

### 2.6 收尾方式

首页最后一块是墨色订房带，电话和复制微信号。页脚是自己的版权、备案号和两个码位。
